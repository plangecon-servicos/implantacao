Tempo do 2º Assinante

Intervalo entre a aprovação do 1º assinante e o visto do 2º assinante (fiscal ou líder).

Fórmula: Data Assinatura 2 - Data Assinatura 1

Observou-se alta eficiência nesta etapa: 75% dos relatórios são assinados em até 4 dias após a liberação da 1ª assinatura.

Indicador 4 Média: 9,7 dias

Tempo do 3º Assinante

Aplicável a RDCs que exigem um 3º nível de validação executiva/cliente antes da aprovação final.

Fórmula: Data Assinatura 3 - Data Assinatura 2

Apenas uma parcela dos contratos exige 3 assinaturas (ex: Pedro Pereira ➔ Jhonata Diniz ➔ Evandro Moraes).

Código DAX para Power BI (Adaptado aos Nomes da sua Base): Pronto para Colar 
// 1. Tempo de Criação
Tempo_Criacao = DATEDIFF(Tabela[Data], Tabela[Data_Criacao], DAY)

// 2. Tempo do 1º Assinante
Tempo_Assinante_1 = DATEDIFF(Tabela[Data_Criacao], Tabela[Data_Ass1], DAY)

// 3. Tempo do 2º Assinante
Tempo_Assinante_2 = DATEDIFF(Tabela[Data_Ass1], Tabela[Data_Ass2], DAY)

// 4. Tempo de Pendência
Tempo_Pendencia = 
SWITCH(
    TRUE(),
    Tabela[Workflow] = "Recusado", BLANK(),
    ISBLANK(Tabela[Data_Ass1]), DATEDIFF(Tabela[Data_Criacao], TODAY(), DAY),
    ISBLANK(Tabela[Data_Ass2]), DATEDIFF(Tabela[Data_Ass1], TODAY(), DAY),
    0
)
